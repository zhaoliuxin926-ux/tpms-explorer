浏览器里拖动滑块，0.1 秒就能给出一个骨支架的等效模量 $E^*$ 和渗透率 $K$。用起来很爽，但问题很快来了：**这组毫秒级算出来的数字，到底能不能用来拍板打印？**

过去几年里，开源几何工具最容易滑向一种自嗨——网页上画得漂漂亮亮、拟合一条文献曲线就算「可信」。为了把这件事拆明白，我在十一月把 TPMS Explorer 拆成四级保真度，拿到真刀真枪的求解器里拉练了三周：

- **T1**：浏览器端解析幂律代理（毫秒级）
- **T2**：浏览器端内置体素求解器
- **T3**：WSL OpenFOAM v13（有限体积真实流体解）
- **T4**：本机 ABAQUS 2025（十节点二阶四面体 C3D10 有限元）

这一轮跑下来，50 道全绿门禁照样拦不住一连串翻车。好在每次翻车都留下了真数字，也倒逼出几条以后可以直接复用的工程规矩。

## 一、586 倍双向失真：一个不得不贴黄牌的体素求解器

第一场对拍打在流体渗透率上。同一套参数（Gyroid solid_network，孔隙率 $\varepsilon = 0.699$，单胞 $4\text{ mm}$），先丢进平台自研的体素 FVM Brinkman 近似器，算出来的渗透率是 $K = 0.0675\text{ mm}^2$；接着导进 WSL 里的 OpenFOAM v13 跑通 147 步收敛，真解只有 $1.15 \times 10^{-4}\text{ mm}^2$。

差了 **586 倍**。

拿到这个数时第一反应是自己写错了量纲或边界条件。为了排查，我拿直方管做了一组解析对照：在解析 Poiseuille 截面下，这个 24³ 体素近似器在近壁面加的 Brinkman 阻尼直接把 6 格宽的直管流道堵死，压降高估了 **31 倍**；反过来塞进弯曲螺旋的 Gyroid 孔道后，因为网格分辨率太粗、孔道内部缺少真实几何的形状阻力拖曳，压降又被低估了 **413 倍**。

一正一反，双向失真。这属于体素离散近似格式在 24³ 尺度下的结构性局限，改两行参数救不回来。

按过去的习惯，人们要么悄悄把这个模块藏起来，要么在文档角落写一句「仅供参考」。我们的做法更直白：直接在后端和 JSON 返回体里硬注入一条字段——`fidelity_warning: "SMOKE_TEST_ONLY_DO_NOT_CITE"`，同时把 DSH 工作台对应的卡片标黄，写死它只做链路贯通冒烟，物理真值以 WSL OpenFOAM v13 为准。

**如果一个代理算不准，最好的止损策略就是让它自己大声报警，绝不让下游 Agent 当真话往下传。**

## 二、收敛到 $10^{-13}$ 的「死腔伪值」与 v13 语法断代

切到真解算器 OpenFOAM v13 并不意味着立刻风平浪静。

第一版单胞周期边界算例跑得极其漂亮：残差一路降到 $10^{-13}$ 机器零，算出来的渗透率 $K = 1.53 \times 10^{-4}\text{ mm}^2$，前后改一版代码复算也几乎纹丝不动。但和 Kozeny-Carman 经验公式一对比，差距超过 200 倍。

把流场切片和边界补丁面数调出来一看，当场傻眼：`xperiodic_on_*` 上的面数恒为 `0`。原来 OpenFOAM v13 的 `createNonConformalCouples` 面向的是内部挡板，对于外部周期面根本没有完成流耦合迁移——两端入口速度死死卡在 `(0,0,0)`，整个算例其实是一个全封闭盒子里的内部回流死腔！残差越干净，说明在死腔里打转越稳定。

同时踩中的还有版本断代坑：模板里的 `surfaceFieldValue` 沿用了旧版的 `regionType + name` 写法，v13 的 `foamRun` 启动即报 `FATAL IO ERROR`，必须改写成 `patch <name>` 选择器。

定位清楚后，我切到了路线 B（`inlet` / `outlet` 压差驱动通透池，四周给定壁面边界）。改完重新开闸，同一组几何的体积流量直接暴涨 **529 倍**。紧接着用 lvl2（83,900 单元）与 lvl3（299,600 单元）做网格无关性检验，结果分别是 $0.0808$ 和 $0.0811\text{ mm}^2$，偏差只有 **$0.44\%$**。

至此，四点（$\varepsilon \in [0.50, 0.80]$）通透池标定曲线才算稳稳落袋：$K_{\text{cell}} = 0.461\,\varepsilon^{3.17}$（$R^2 = 0.998$）。

## 三、反转之反转：被三胞「命中」又被外推推翻的物理直觉

单胞算准了，但工程试样往往不止一个单胞。为了量清楚进口和出口端的旁路效应，我把计算域拉长到双胞（$k_2$），在四档孔隙率下重新跑完一轮对照。

数据很干净：双胞比单胞系统性低了 $3.75\% \sim 4.26\%$，均值是 $-4.06\%$，窄带内基本与孔隙率无关。于是标定线给出统一修正系数 $0.9594$，得到实用交付口径：

$$K_{\text{true}} = 0.442\,\varepsilon^{3.17}$$

接着我把这组曲线发给外部审稿 AI（Gemini）做独立挑战。对方立刻敏锐地提出两点质疑：
1. 为什么你的 `CFD / KC` 比值随孔隙率上升在单调走高？是不是端盖面污染了你的比表面积 $S_v$？
2. 按串联水阻渐近公式推演，三胞（$k_3$）比单胞的渗透率比值应该落在 $K(3)/K(1) = 0.9467 \pm 0.006$。你敢不敢补算一组 $k_3$ 验证？

这正是验证文化最迷人的地方：**对方给了可证伪的数值预言，跑一次就见分晓。**

第二天三胞网格（197,879 单元）跑完，结果如下：
- **三胞实测**：$K(3) = 0.137993\text{ mm}^2$，$K(3)/K(1) = 0.9458$，正正好好落进预言区间 `0.9467 ± 0.006`。
- **比表面积勘误**：我顺着第一问逆向拆解了旧 KC 表格，发现旧公式里隐含的比表面积居然随孔隙率升高而上涨，违背物理常识。用 STL 网格真实面积重算 $S_v$ 后，真实比表面积如期下降 $19\%$，重新算出来的 `CFD / KC` 全部收敛到 $< 1$（$0.522 \to 0.371$），对应的真实 Kozeny 常数从 $9.57$ 爬升到 $13.48$——三维鞍部喉道造成的额外形状阻力与迂曲拖曳完全对上了流体力学直觉。

故事到这里看似大团圆，但当天晚上做完 $N=1,2,3$ 的渐近外推（拟合 $1/K(N)$ vs $1/N$，$R^2=0.9992$，外推出无限周期本征值 $K_\infty = 0.1342\text{ mm}^2$）时，我们突然意识到一个必须诚实更正的细节：

**实测的 $K(N)$ 是随胞数 $N$ 单调递减的（$0.1459 > 0.1397 > 0.1380 > 0.1342$），而串联阻力模型假定端阻串联时，预言的是 $K(N)$ 随 $N$ 递增！** 所谓 $k_3$ 命中，其实是两条方向相反的曲线在有限区间内恰好做了一次两点内插巧合。

我们没有把这段当作「高光预言命中」吹进文档，而是在 [cfd-calibration.md](../cfd-calibration.md) 明确加了一节「诚实更正」：把 $0.9594$ 定为 $N=2$ 实用交付口径，把 $K_\infty = 0.1342\text{ mm}^2$ 单独列为 $N\to\infty$ 的渐近下限参考。

## 四、ABAQUS C3D10 的 $-1.07\%$ 与最后那 $0.02\%$ 去哪了

力学侧的剧本同样先抑后扬。

把平台生成的 R20 隐式网格转成 ABAQUS `.inp` 后，最初两次提交全被前处理直接打回。抓出来是 `sim/p2_static_setup.py` 的一个隐蔽缺陷：输出请求设置了 200 个点，却漏掉了 `*STEP, INC=1000`，默认步长上限 100 导致求解前直接报错退出。补上这一行后，83,540 个 C3D10 二阶单元顺畅算完，弹性段 51 点回归 $R^2 = 1.000000$，得到等效模量：

$$E_{\text{eff}} = 138.29\text{ MPa}$$

拿这个 T4 独立链的盲测结果去对拍 T1 的幂律代理（$E^*/E_s = 0.9914\,\hat{\rho}^{2.2028}$）：
- $70\%$ 孔隙率点（$\bar{\rho} = 0.30$）预测值 $139.8\text{ MPa}$，偏差 **$-1.07\%$**；
- $50\%$ 孔隙率点（$\bar{\rho} = 0.50$）偏差 **$-0.90\%$**。

两个点都在 $1.1\%$ 以内，看起来已经够准了。但再往下挖一步——那 $-1.07\%$ 到底从哪来的？

我把送进 ABAQUS 的那份 R20 STL 文件拿来称了一下实际固相率，发现由于 Marching Cubes 等值面离散的体积亏损，名义 $70\%$ 孔隙率的试样实际相对密度并不是 $0.3000$，而是 **$0.2982$**（50% 试样实际相对密度是 $0.4970$）。

把这组网格实测 $\bar{\rho}$ 代回同一条幂律公式，结果出来了：
- p70 点偏差从 $-1.07\%$ 缩到 **$+0.25\%$**；
- p50 点偏差直接缩到 **$+0.02\%$**。

原来那 $1\%$ 左右的差距，几乎全部是体素离散的几何体积账差，力学幂律本身与 C3D10 全三维有限元的重合度已经逼近了小数点后两位。

最后一步是仓库瘦身。把 35 个历史标定 ODB 文件（整整 18 GB）通过 `abaqus python p2_extract_csv.py` 全部提取成 1 KB 一份的标准位移-载荷曲线归档进 `sim/csv_archive/`，再加上 T4 静态 ODB 的清理，整个本地仓库从 **32 GB** 压回 **2.4 GB**，全部证据链继续随 Git 完整保存。

## 五、这一轮沉淀下来的四条死规矩

跑完这套四级对标后，留给项目最值钱的不是几组系数，而是四条直接写进代码和门禁里的规矩：

1. **分级披露比强行拟合值钱**：[fea-calibration.md](../fea-calibration.md) 明确写死——线弹性 $E_{\text{eff}}$ 是 T4 双点盲测认证的代理；而大变形屈服强度 $R_{p0.2}$ 与平台应力当前仍属于经验外推，在 Explicit 塑性段交叉核验跑通之前绝不混标「已认证」。
2. **不准的求解器要自带「警报器」**：FVM 体素求解器保留为冒烟档，输出必带 `SMOKE_TEST_ONLY_DO_NOT_CITE` 标识，从数据结构层面防止上层 Agent 误引。
3. **跨机和跨会话不能靠人肉对齐**：`tpms/.verify/docs_consistency_check.mjs` 不只锁 `README`，还把总览文档、诚实边界生成脚本和博客粘贴版全部纳入单命令扫描，谁修改了数字没同步，门禁当场亮红灯。
4. **所有推论都要给得出复现入口**：从双壳驾驶舱 `platform/harness.html` 到 `sim/csv_archive/`，每条曲线、每次失败和每次推翻都能顺藤摸瓜查到原始脚本。

下一程的棋盘已经摆好：本机 ABAQUS Explicit 塑性段核验、S1 实物试样上机压缩，以及用真实验曲线喂给 `fit-batch.mjs` 完成物理闭环。工程嘛，不怕数字打架，最怕的是不敢拿真解出来打一架。
