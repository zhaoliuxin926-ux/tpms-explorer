## 掘金步骤（每篇约 2 分钟）

1. 掘金 → 写文章 → 粘贴全文（Markdown 编辑器原样保留）
2. 文章封面：无图可用，掘金会自动取首屏排版——可选上传仓库根 `docs/screenshots/social-preview.png` 作封面
3. 标签：`前端` `测试` `AI编程`（第一篇）/ `AI大模型` `架构` `安全`（第二篇）
4. 分类：`前端`（第一篇）/ `后端` 或 `人工智能`（第二篇）
5. 发布前预览：确认代码块高亮正常、末尾 GitHub/Pages 链接可点

## 知乎步骤（每篇约 3 分钟）

1. 知乎 → 创作中心 → 写文章 → **粘贴前先切到 Markdown 编辑器**（设置里可切换），粘贴全文
2. 知乎会保留标题层级/代码块/表格/引用；粘贴后目检一遍首屏
3. 文末两个在线体验链接（GitHub Pages）知乎会渲染为卡片，保留即可
4. 话题标签：`编程` `软件工程` `人工智能`（第一篇）/ `大模型` `AI编程`（第二篇）
5. 无需封面图（知乎可选）
