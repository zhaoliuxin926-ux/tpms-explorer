# TPMS 试样 FDM 打印参数建议（拓竹 P1S · PLA）

> 依据：形态拍板 2026-11-08（network solid 终态）+ FDM 工艺约束。配合
> [PHYSICAL_TESTING_PROTOCOL.md](../PHYSICAL_TESTING_PROTOCOL.md) 使用；打印后按协议做压缩试验，CSV 回传即反演。

## 形态与几何约束（network solid）

| 参数 | 建议 | 依据 |
|---|---|---|
| 形态 | **network（solid）**——不要选 sheet 薄壁 | FDM 0.4 喷嘴最小稳定壁 ~0.8mm（两道壁）；network 杆径 ρ̄=0.3 时 450–600μm≈1–1.5 喷嘴宽，贴近下限可打；sheet 150–200μm 低于极限 |
| 族 | **Gyroid 首选**（自支撑旋曲面、免支撑、各向同性）；Diamond 次选 | FDM 悬垂角友好 |
| 周期数 k | 试样线径 < 12mm 时 **k=2~3**；k 太大单杆过细 | 杆径 = f(ρ̄, 周期) |
| 相对密度 ρ̄ | 0.3 / 0.4 / 0.5 三档（标定线主域） | fea-calibration 幂律域 k≥2 |
| 杆径自检 | 切片软件里量最细杆 ≥ **1.0mm**（≈2.5 倍线宽），不足就放大 L 或降 k | FDM 可打印性红线 |

## P1S 参数建议（PLA）

| 项 | 建议 | 说明 |
|---|---|---|
| 喷嘴/线宽 | 0.4 / 0.42 | 缺省 |
| 层高 | 0.16–0.20mm | 旋曲面层高过大会台阶化壁面 |
| 壁面 | **壁圈 3–4 圈**（Arachne 允许变宽） | TPMS 杆件全由壁构成——壁圈数=杆径精度 |
| 填充 | **100%**（试样必须实心网络） | network 固相即填充；保形优先 |
| 速度 |外壁 ≤200mm/s，别用狂暴模式 | 壁面质量>速度 |
| 温度 | PLA 220±5°C（Bambu PLA 基本款按线材说明） | 层间结合决定压缩失效模式 |
| 干燥 | 打印前烘料（PLA 55°C/6h） | 湿气=层间缺陷=力学数据噪声 |
| 支撑 | **无**（Gyroid/Diamond 自支撑） | network 全程自支撑是选它的主因 |
| 方向 | Z 向 = 压缩试验加载向，**与 FDM 层间弱面重合**——这是 FDM 试样的固有属性，如实标注数据口径 | 层间 τ 弱于面内，压缩模量/平台段会受影响；反演时按 FDM 口径解读 |
| 热退火 | **不做**（PLA 退火收缩变形破坏尺寸公差；如需热稳定性换材料另议） | |

## 上机口径注意

1. **打印件 = FDM 口径**：层间各向异性 + 壁面粗糙（Ra 明显高于 DLP）——与平台 C3D10 理想几何对比时存在系统性差异，属 FDM 固有属性，反演报告如实披露。
2. **质量门**：打印后先目检杆件连续性（断杆/拉丝=参数问题），再上天平称重对比 STL 体积（相对密度实测口径，与 fea-calibration 的 ρ̄ 对账）。
3. **试样尺寸**：沿用 specimens/S1_G60 口径（k8 R96 = 12 格/周期）时杆径偏细，**建议首批先打 k2~k3 的粗杆验证打印工艺**，再上细杆试样。
4. 压缩试验后 CSV 按 fit-batch CSV 契约回传（表头+三尺寸元数据必填，契约见 tpms/agent/fit-batch.mjs 头注与 agent_memory 登记）（表头+三尺寸元数据必填），工位自动反演+幂律叠图。
