### 🎯 Pareto 多目标探索器全家（前沿 → 过滤 → 混合 → 逆设计）
- **前沿探索**：26 族×孔隙率×密度毫秒级解析代理扫描（实测 832 点→非支配前沿 199 点）→ log-log 散点（Sv 色标）→ hover 读数 → **点击写回设计参数**（三难权衡：E↑力学 × κ↑传质 × Sv↑生物活性）
