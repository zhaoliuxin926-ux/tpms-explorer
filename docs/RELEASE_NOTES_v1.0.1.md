# Release Notes — v1.0.1（覆盖收口批）

> 2026-09-20 · 累计 v1.0.0-stable-epoch 后五轮审查修复 + 交互面门禁固化 + GPU 实测

## 修复（真机走查抓出，全部默认配置可复现级）

1. **GPU 场计算 submit 缺 `.finish()`（重大）**：`evaluateFieldGPU` 提交的是编码器对象而非
   命令缓冲，TypeError 被 catch 吞成静默 CPU 回退——**WebGPU 加速自 v3.0 上线以来从未真正
   执行过**（状态行「可用·已启用」为真、求值永假；门禁对拍 jsEval VM 不触浏览器路径故全绿）。
   修复 + 类型垫片补全 `finish()`；修复后真机端到端激活（状态行实报「WebGPU V 场 23.7ms·61³」）。
2. **弹塑性压溃三连修**：σy/E 单位错 1000×（880MPa/110GPa 裸除得 8.0，应 0.008——屈服应变
   虚高致求解退化）；孤立体素致 K 奇异（R=6/8 粗网格高孔隙支化天然碎片，此前默认配置 100%
   报错）→ 边界连通 BFS 剪除+结果如实披露剔除量；坍塌 ε=undefined 文案判空。R 6→8。
3. **声子能带采样简并**：N=6 体素格 × 奇数周期 k=3 精确落 cos 零点（场恒 0→固相 0 点），
   默认配置 100% 报「固相质点过少」→ N=7（奇数 N 数学上任意 k 免简并）。
4. **逆向「应用最优解」缺 updateBadges**：应用 Schwarz 解后标题/徽标滞留 Gyroid（NL 修复
   c298f68 的同族漏网）→ 对齐编程式应用范式（+updateBadges+scheduleHdUpgrade）。
5. **NL 钳制域对齐 + 构建失败持久空态**（47d8eb6）与**NL syncUI**（c298f68）与**真机体验
   9 项清账**（226e59d）随本版一并收录。
6. **非欧映射几何约束守卫**：圆柱 R>域半宽/环面双半径约束此前仅文档披露，现切换/调 R 时
   toast 提示（不阻断）。

  声子/压溃/GPU 三个均属此类）转化为 CI 永久拦截。
