## 新能力（用户可见）

- **LLM Agent 显式会话**（`--session`）：推荐结果跨进程留痕，后续指令可确定性指代候选——「把第二个构建出来」不经模型直接绑定推荐参数；指代安全边界=**完整匹配的有限肯定句式白名单**，否定/多候选/附带参数修改一律结构化拒绝并说明原因（不静默误执行）
- **有界多步任务管线**（`agent-pipeline`）：推荐→候选选取→构建→水密验收→悬垂可打印性，一步到位；三层口径报告（解析代理非 FE / 网格实测 / 工程阈值）；预算（步数/调用数/总时长/子进程超时/修复顺延）全程钳制——总时长预算约束到正在执行的子进程；所有失败路径（含非法参数、损坏会话）输出 stdout 结构化 JSON
- **Anthropic 兼容通道工具历史**：多轮 tool_use/tool_result 按 ID 关联（Coding Plan 订阅直抵）
- **Octet 桁架焊接解锁**：12 杆结点 Newton 投影重合短边经 surface-nets 焊接根治（流形边零操作、已测范围 BCC 字节级不变）——**S7 真 BCC + S8 真 Octet 桁架双极对照齐，32 件试样全部通过水密交付门**，具备进入打印验证条件
- **Agent 可靠性收口**（三轮独立审计+复核）：错绑候选、早退裸崩、预算穿透、末步假成功、错误路径回归依赖"恰好拒产"五类缺陷根修；错误路径改**可控故障注入**（可替换执行器夹具），不再依赖任何几何族的真实失败
