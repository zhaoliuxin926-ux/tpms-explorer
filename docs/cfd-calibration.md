# CFD 标定线 — TPMS gyroid K(ε) 幂律（通透池压差驱动口径）

> 与 docs/fea-calibration.md（FEA 力学线）平行的 CFD 渗透率标定权威文档。数据真源：sim/cfd/tpms_cell/K_scan_result.json（k1 单胞）+ k2_scan_result.json（k2 双胞入口效应对照）。

## 口径（先读）

- **链路**：p3_fluid_domain R48 STL → strip_caps 剔端盖 → snappyHexMesh lvl2 无棱（定案参数）→ 通透池压差驱动（x 两端 Dirichlet，y/z 壁面）→ foamRun incompressibleFluid → K = ε·Ubar/(ΔP/L)
- **梯度口径**：ΔP/L = 5.089/2π = 0.8099 mm/s²（mm 制，ν=1 mm²/s）
- **单位**：K [mm²]；Ubar 由 volFieldValue 全域平均反读

## 入口效应修正（k2 双胞对照，2026-11-15 四点实测定案）

- 同链同梯度唯一变量=胞数：k2 双胞 [0,4π]×[0,2π]² 对照 k1 [0,2π]³
- 四点入口效应：p50 −4.0% / p60 −3.75% / p70 −4.26% / p80 −4.22%——**窄带 −4.26~−3.75%（均值 −4.06%），端部效应与孔隙率基本无关**
- **统一修正因子 0.9594**（K_true = K_cell × 0.9594）；单胞口径高估机制=Dirichlet 端部低压降伪影在 1 周期域占比过半
- **适用边界**：同链+R48 STL 网格档内有效；升 lvl3 或换驱动口径时端部伪影不同步收敛，**0.9594 不可跨档引用**（跨档需重做 k1/k2 对照）

## 入口效应机制锁死与 KC 对照勘误（2026-11-15 深夜，Gemini 回执四问闭环）

**k3 预言验证命中**：Gemini 串联水阻渐近律预言 K(3)/K(1)=0.9467±0.006 → k3 三胞 p70 实测 0.137993 mm² → **0.9458 命中**——"端面迂曲旁路"机制（k=1 端面短程旁路 vs k≥2 胞间流线连续性）与统一修正因子 0.9594 被三胞实验锁死。k3 链资产：blockMeshDict.tpms_k3/snappyHexMeshDict.scan_k3/run_tpms_k3.sh（63×21×21 背景/197,879 cells Mesh OK）。

**KC 对照口径勘误（重要更正）**：Gemini 逆向取证发现旧 K_kc 表的隐含 Sv 序列（0.9568→1.1229）随 ε 上升——物理反常（真实内界面应随 ε 下降 ~19%，STL 面网格实测 0.4990→0.4033 证实）。我方交叉实证：反解数字与旧 K_kc 精确吻合（取证成立），但端盖归因部分修正（我方 scaffoldWall STL 为面网格，无截断面污染；反解序列≈实测+端盖口径，偏差 2-5%）。**结论不受影响：旧 K_kc 作废**。STL 实测 Sv 权威重算：

## 口径层级澄清（2026-11-16，k∞ 三点渐近外推）

三点（N=1/2/3）线性外推 1/K(N) vs 1/N（R²=0.9992）：**K∞=0.1342 mm²（N→∞ 渐近本征值）**，层级 K(1)=0.1459 > K(2)=0.1397 > K(3)=0.1380 > K∞=0.1342。

**诚实更正**：实测 K(N) 随 N **递减**，与 Gemini 串联阻力模型（α>0，预言 K 随 N 增）**方向相反**——k3 预言"命中"实为模型形式的两点内插巧合（数值对、方向存疑）。正确机制：端面旁路使 k=1 表观 K 偏高，N→∞ 全流线走完整三维迂曲 → K∞ 为真本征值。

**口径层级（标定线交付以此为准）**：
- `0.9594`（K_cell×0.9594）= **N=2 口径实用修正**（实测基准，推荐交付口径）
- `K∞=0.1342`（幂律 0.421·ε^3.17 换算）= **N→∞ 渐近参考**（比 N=2 再低 ~4.1%，披露供保守估计）
