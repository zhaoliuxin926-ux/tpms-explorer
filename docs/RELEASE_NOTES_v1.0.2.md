# Release Notes — v1.0.2（性能+求解器收敛批）

> 2026-09-20 · GPU 缓存 ≈3.7× · 弹塑性压溃 k1 域完整可解 · 门禁 12→14

## 性能

- **GPU 设备/管线跨重建缓存**：修复 finish() 激活 GPU 路径后的第二轮优化——一次性模式
  每次重建重复创建 adapter/device/shader/pipeline（~20ms），缓存复用后实测稳态
  **129³ 56→15ms（≈3.7×）**、97³/65³ ~7ms（8×）；应用内预览档状态行 23.7→7.6ms；
  场值逐点不变。BENCHMARKS §六 已入缓存前后对照表。

## 求解器

- **弹塑性压溃收敛性双修（缺一不可）**：屈服启始折点处弹性预测方向过冲，原浅回溯
  （4 级到 α=1/8）全部越过折点导致 Armijo 假失败——深回溯（α→1/512）+ 非单调接受
  （≤1.5× 最小残差步）后，p75 k1 可解前沿 ε=0.0063→0.0225；**浏览器端到端完整结果**：
  坍塌@ε=1.5% + σpl 有限 + DT/GA=0.82 + PEEQ 真塑性 + 22.6s（原 7 分钟不可解）。
- **压溃体素化解析化**：6 解析族与 isSolidAt 共用 analyticFieldValue（单一语义源）——
  查表版插值噪声会翻转边界格、劣化细长骨架承载路径（探针实证同参数解析掩码收敛、
  查表掩码步 2 败）。
- **取证钩子沉淀**：runNR 的 NaN 早退/线搜索失败两分支暴露 __plasNaNDbg/__plasLsDbg
  （零开销 debug hook），本轮根因定位全链依赖它们。
