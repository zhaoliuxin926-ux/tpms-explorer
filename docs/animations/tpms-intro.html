转动的截面：Gyroid 是怎么"长"出来的

极小曲面听不懂？没关系——先看动画。下面每一个画面都是 Gyroid 的一个水平切片： 平面 z = z₀ 横扫立方体时，切到曲面的位置画出一条条曲线。切片连续转动，曲线连续变形—— 把几十万个这样的切片叠起来，就是一个 Gyroid。

z₀ = 0.00 rad
拖动滑块手动扫切片
F(x, y, z) = sin x · cos z + sin y · cos x + sin z · cos y   →   曲面 = { F = 0 }
固相一侧（F < 0） 孔隙一侧（F > 0） 曲面本身（F = 0 等值线）

看懂这三步，TPMS 就入门了

① 公式只是"高度场"：把 F 想象成一片起伏的地形，每个点 (x,y,z) 都有一个高度值。
② 等值面 = "海拔 0 的等高线"的 3D 版：F = 0 的点连成一张光滑曲面——它就是 TPMS。
③ 改公式 = 捏形状：换掉 sin/cos 的组合（Diamond、Schwarz P…）或拖动权重，曲面族就变了； 上下平移 F（改变等值常数 C）就在"胖"与"瘦"之间调孔隙率。
