## 一、简历项目条目（两版）

### 完整版（项目经历栏，4-6 行）

**TPMS 结构参数探索器 / TPMS Explorer** —— 独立负责的浏览器端生成式设计平台（个人项目，2026.07–至今；密集开发期 2026-07~09）
- TypeScript + Three.js + WebGPU：**工程版** 24 族 level-set 曲面、多物理场估算与制造导出（STL/INP/OpenFOAM/MATLAB；G-code 已进导出中心（单壁+扫描填充，诚实边界见 HONESTY_BOUNDARIES））；**教学版**单文件 8 族 file:// 双击零安装（功能冻结）。
- **46 道 CI 门禁三平台矩阵**（1000+ 断言）：数学四方同源对拍（容差 1e-9~1e-12，非位级）、水密性/非流形审计、GPU/CPU 万点对拍、红队极端工况矩阵——以「可证伪的验证文化」而非代码量构筑可信度。
- **LLM Agent 工程链**：NL→tool calling→schema 校验拦截（越界拒绝）→CLI 闭环（M0-M5 六阶段），三 Provider 抽象 + 37 条中英 dry-run 槽位回归（glm-5.3-flash 多轮 37/37（C3 缓解后 n≥2；缓解前 36/37 与 37/37 并存，勿称确定性）；端到端另有 Mock 6/6 + 真实抽测 2/2），红队加固（路径穿越/参数注入/原型链绕过）。
- **对抗式质量方法**：按轮入账的走查+红队审查（v2 轮 5C+20M 全修；寿极 v3 轮 0C+10M+20m 全修；Agent 面两轮 2H+7M+5L）——含「GPU 加速上线三周从未真正执行」「采样网格与周期共振导致默认配置必败」「几何刚度矩阵行列倒置使屈曲捕获功能死亡」等门禁盖不到的缺陷；每类缺陷转化为永久 CI 哨兵。当前发布态 open Critical=0。
- **多 AI 平台接力开发**：主修（ZCode）与优化批（Mimo/另一模型）双平台协作，建立交接纪律（记忆文件强制更新/推送前全量验证/禁并行写入）；我对架构、验收与红队裁决负责，实现以 AI 结对/接力为主。

## 二、面试 3 分钟 demo 脚本

**第 0 分钟（30s）——定位**：「这是一个跑在浏览器里的工业设计工具：左边调参数，右边
实时生成可用于 3D 打印的多孔结构。我独立完成从数学内核到 CI 到 LLM Agent 的全部工程，
并用两个 AI 平台接力开发——一个修主线，一个做优化批。」

**第 1 分钟（60s）——产品面**（操作：拖孔隙率滑块→切曲面族→开剖切）：
- 拖滑块：等值面亚秒级重建（350ms 防抖窗口+Worker 后台计算），顶栏工程指标（模量/屈服/渗透率/比表面积）实时联动；
- 数字键切族：24 族曲面数学同源（渲染查表/CLI/GPU/MATLAB 四方对拍门禁守护）；
- 剖切滑块：连通性预检卡自动弹出——贯通通道/死腔/孤岛/截面孔隙率，骨支架设计刚需。

**第 2 分钟（60s）——工程深度**（切到 GitHub）：
- 打开 Actions：三平台 46 门矩阵，「我不靠口说正确——数学对拍、水密审计、红队矩阵、
  GPU/CPU 双跑对拍都在 CI 里」；
- 打开 llm-agent：自然语言「孔隙率 85%，Diamond，2mm 端板」→ 结构化工具调用 → 参数
  落地，「这是完整的 tool-calling 工程：schema 拦截、越界拒绝、Provider 抽象」。

**第 3 分钟（60s）——质量方法论（差异化核心）**：
- 「最有代表性的一件事：所有测试全绿，但真机走查发现 GPU 加速从未真正执行过——一个
  submit 缺 finish() 的 TypeError 被 catch 吞掉、静默回退 CPU 三周，而类型垫片缺口
  被 as unknown 绕过、门禁对拍不触浏览器路径，三层防线全部失效。我逐层探针定位、修复
  后实测出性能数字，再优化一倍，并给这类『门禁盖不到的接线层』写了新的冒烟门禁进 CI。
  这个项目教我的正是：**验证体系本身也需要被对抗性验证**。」

## 三、高频追问弹药库

| 可能追问 | 回答要点（全部有实据） |
|---|---|
| 「怎么保证数学是对的」 | 四方同源对拍门禁（parity_math 332 断言）：查表渲染/解析式/GPU WGSL/MATLAB 同一公式互拍（容差 1e-9~1e-12，非位级）；孔隙率二分用 exact 解析求根+网格割线校正（Diamond R96 实测偏差 0.13pp，单族口径见 BENCHMARKS §1） |
| 「LLM 部分具体做了什么」 | M0-M5：Provider 抽象（Ollama/智谱 API/Mock）→ NL→工具调用 → tools.schema 参数校验拦截 → CLI 执行 → 有界修复策略闭环；37 条中英回归（glm-5.3-flash 多轮 37/37（n≥2，勿称确定性）；四档模型均有分档战绩）；红队清单：路径槽位零校验=任意写、`in` 原型链绕过、多 schema 同槽位口径分裂、校验死代码 |
| 「性能怎么优化」 | WebGPU compute IR 双后端（同一指令集编译 WGSL+JS VM，万点对拍相对误差 ≤1e-6）；**真机实测分规模两线：129³ 全量场 56ms → 设备/管线缓存后 15ms（≈3.7×）；61³ 预览档 23.7ms → 7.6-8.8ms**（两条测量线，不可串成单一加速链）；公网加载优化：自写 gzip 静态服（当前首屏 ~283KB gzip：three.js 分包 ~182KB + 自研主包 ~101KB（268KB raw，2026-09-25 动态分包后））；按需渲染（静止零 draw call） |
| 「最大的坑」 | 五轮审查抓的任意一个都可讲：声子卡 N=6×k=3 采样网格精确落在 cos 零点→场恒零（页内复算 0/89 点实锤，奇数 N 数学免疫）；geo 切线行列倒置——v6.0 起屈曲捕获功能从未存在，修复后用「迭代路径分叉」活性断言防回退；压溃卡 σy/E 单位错 1000×（MPa/GPa 裸除） |
| 「多 AI 平台协作怎么做」 | 双平台接力：主修平台修主线+对抗审查，优化平台做独立批次（CI 基建/文档口径/拆分重构）；建立三条交接纪律——记忆文件强制更新（git 不是交接面）、推送前本地全量验证（未推送=未验证）、禁止并行写入+扫仓提交；人类负责仲裁分歧（如拆分重构的立项决策）与最终验收 |
| 「为什么不用 React/后端」 | 单文件 file:// 双击即用是交付需求（实验室电脑零安装）；复杂度按需引入——这个决定让交付物零构建链依赖（当前首屏 ~283KB gzip 含 three.js 分包） |
| 「测试怎么设计的」 | 断言反作弊审查（恒真断言五类特征）、pass 下限守卫（防断言集体跳过）、静态字符串哨兵（改公式必炸镜像断言）、活性钉（死实现与正确实现输出恒等时用迭代数分叉判活） |
| 「产品权衡的例子」 | 反演求解器解域 [2,98] vs UI 滑块域 [60,90] 冲突：二选一困境（扩滑块损产品口径/收窄求解损保真）→ 第三方案：求解保持宽域、应用时钳回 UI 域+如实披露 toast+静态哨兵锁定——兼得求解能力与显示诚实 |
