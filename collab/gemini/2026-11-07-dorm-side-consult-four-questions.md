## 背景（一段话 + 一张数据表）

我们在做仿生骨支架的 TPMS（三周期极小曲面）仿真管线：Python 隐式场 f(x,y,z)（gyroid = sin x cos y + sin y cos z + sin z cos x）→ marching cubes 提取水密 STL → Gmsh HXT 二阶四面体（C3D10）→ ABAQUS 压缩仿真 → CSV 契约 → ISO 13314 反演。两种形态：**network**（固相 = f≥c 单侧阈值，杆/面网络）与 **sheet**（固相 = |f|≤t 绕中面对称区间，薄壳片）。已实测定案的事实：

| 事实 | 数据 |
|---|---|
| network gyroid 幂律（ABAQUS 标定，C3D10，k≥2 域 ρ̄∈[0.3,0.5]） | E*/Es = 0.9914·ρ̄^2.2028（STL 实测密度口径）；强度侧 Rp0.2/σys = 0.54·ρ̄^2.02、平台σ/σys = 1.64·ρ̄^2.41（屈曲加权，Explicit） |
| 拓扑实测（trimesh 域分解） | network：固相单连通 + **孔隙单连通**（单侧切割 c≠0 仍逾渗）；sheet：固相单连通片 + **孔隙真双迷宫（G+/G- 两域体积 50.0%/50.0% 精确对称）** |
| sheet 网格（k2 R24 每 24 格/周期，薄壁 t≈0.53 场单位） | 19.8 万 C3D10/minSICN 0.046（与 network 同量级）；内部粗化已证伪（<0.05 单元暴涨 480×）；STL decimation 已证伪（水密破坏+体积塌 88%） |
| MC 清洗副作用 | pymeshfix 兜底后偶现 4 三角孤立微壳（体积 0.003mm³，占 0.0002%）——已加体积占比 <1% 告警 |
| 骨支架设计指标 | 多目标：模量匹配骨骼（防应力屏蔽）× 渗透率 × WSS 窗口 × 比表面积；打印 LPBF/DLP |

## Q1（最高优先）：sheet 双迷宫的单胞 PBC 流体仿真策略

Phase 3（渗透率/WSS，低 Re 层流，单胞 + 平移周期边界）即将启动。sheet 型的孔隙域是**两个互不相通的迷宫**（各 50%）。问题：
1. CFD 域怎么设：两迷宫**各自**建周期边界分别算（两次仿真，各得一条 K），还是两域放同一个网格一起算（一个模型两不连通域，求解器自动按域解）？
2. 若一起算：入口驱动（体平均速度/压力梯度）在两域怎么分配——两域流量份额由什么决定（对称几何下应各 50%？还是由各自流阻自发分配）？渗透率 K 报告口径取"总体积平均"还是"分域各报"？
3. COMSOL 与 Fluent 各自对"非共形周期对"的支持度：我们的 MC STL 边界面三角不保证跨周期面对应（实测对侧三角计数可不等）。COMSOL 的周期条件用"连续性/保守变量映射"是否支持非共形对？Fluent Meshing 对 periodic 是否强制 conformal（若是，需要 Gmsh 端做周期网格——对 discrete 几何 setPeriodic 的可行性）？
**裁决请求**：给出推荐策略（分/合）+ COMSOL/Fluent 各自的实现路径与坑。

## Q2：network vs sheet 的力学/渗透率文献预期（助力形态拍板）

同固相率下，network gyroid 与 sheet gyroid 的力学与传输性能，文献层面的定量关系是什么？我们已有 network 标定（上表），sheet 尚未标定。已知线索：sheet 类报道的 Gibson-Ashby 指数带 n≈2.0~2.3（我们 network 实测 2.20 同带——但形态不同不能直接比）；sheet 双流道是换热器主流形态。问题：
1. 同 ρ̄ 下 sheet vs network 的 E*、平台强度、渗透率、比表面积——文献有无**同材料同工艺的成对实测**（LPBF 或 DLP 打印对比）？量级差多少？
2. 骨支架语境下两形态的权衡：应力屏蔽（模量匹配）、骨长入（孔隙连通性/孔喉尺寸）、疲劳——文献结论或机制分析？
**裁决请求**：给出可引用的文献结论清单（作者/年份+定量关系），并给"骨支架场景下该拍哪个形态"的倾向意见。

## Q3：薄壁 sheet 网格的各向异性棱柱层路线可行性

sheet 薄壁（几何壁厚 ~0.5-0.8mm）要求壁厚方向多层单元。各向同性四面体在 R24 下已同 network 量级，但若未来 R48/大 k 扫参，内部粗化证伪后唯一存活路线是**贴壁棱柱层（prism/boundary layer）+ 内部粗**。问题：Gmsh 对 **discrete surface**（MC 三角面直接作边界，无法参数化——classifySurfaces+createGeometry 对数万面片实测爆炸 >4min）能否生成 boundary layer？若不能，有没有绕过参数化的棱柱路线（如 Gmsh BoundaryLayer field 对 discrete entity 的支持版本/限制，或第三方面片偏移库如 mmg3d/tetWild 的实践）？
**裁决请求**：可行性判定 + 具体工具/版本/参数路径，或明确的"此路不通"。

## Q4（附带）：MC+pymeshfix 孤立微壳碎片的机制

marching cubes 在 TPMS 等值面与盒 SDF 交线附近产生的三角网，经 trimesh validate + pymeshfix 修复后，偶现 4 三角孤立闭合微壳（0.003mm³）。机制是什么（MC 退化 case 的封闭小环？pymeshfix 缝合副产物？），根治方向是生成端剔除（体积阈值滤除后转 pymeshfix）还是修复参数调整？对力学/流体结果无实质影响（体积占比 2e-6），纯粹是管线洁癖与网格器稳定性问题。
**裁决请求**：机制判断 + 推荐处置。
