# Gemini 正式裁定回执处置（2026-11-04 第二轮）

## Gemini 裁定摘要与 ZCode 复核

### 裁定 1：代码层密度口径 → (a) 两阶段解耦 + gyroid 同步换口径（禁止跨族双口径）
**采纳**。ZCode 复核三处：
- **κ 数值修正**：端点解出 κ_diamond=0.4987/0.5^1.06235=**1.0415**（Gemini 给 1.0454，以其为拟合变体；落地用 1.0415 并披露）；gyroid κ 待从实测端点同法解出。
- **幂律映射采纳但精度声明修正**：Gemini 称区间偏差 <0.1%——实测中点 ρ=0.4 处幂律映射 ρ̂=0.3936 vs 线性映射 0.3936 vs 实测 0.3911，两映射中点误差相当（~+0.6% 密度→E* 影响 ~0.5%），**非 <0.1%**。采纳幂律形态的物理理由（ρ→0 无负密度、与 γ 同构），精度声明按实测披露。
- **成本核算确认**：改 C1_MAP/指数常数+入口映射，无需重跑 FEA（gyroid 实测参数已在档）。

### 裁定 2：p50 放行判据 → ③能量审计 + ④节点对原位修复（与①摘除合并：注释 36886 + *MPC PIN 23775,206 一次 Standard），免除②微偏置
**采纳**（②重网格全局拓扑噪声反污染对照的论证成立；.inp 手术警示专业正确——直接改坐标会重复顶点拒收）。

### 裁定 3：统计规范 → 无信息平坦先验 + 固定 σy；network 双项分解按 Maxwell 语义
**采纳**。复核：
- 无先验 CI 公式复核 ✓：Σ(x-x̄)²=0.1312（x=ln(ρ/0.4)），SE=0.015/√0.1312=0.0414，**CI95=±0.081**（Gemini 前轮 ±0.076 用 Σ=0.148 近似，落地取 ±0.081）；点估计≡OLS ✓ 零先验偏倚 ✓；σ_eff=max(σy, RMSE_ln) 保险采纳。
- Maxwell 语义复核 ✓：Z_crit=6（Maxwell 判据）、octet Z=12 拉伸 ρ¹ / gyroid network Z=3、diamond network Z=4 欠配位弯曲 ρ²——与 strut 族先例（bcc ρ²/octet ρ¹）完全同构，机制表述直接可用。
- α 非负约束预警采纳（n>2 时无约束回归出负 α——来源=鞍点颈缩逾渗+节点粗化 ρ³，如实写入机制段而非硬拟合）。

### 附带机制闭环：float32 量化解释 → **ZCode 实证确认并升级根因**
- 实证：p0 用 `trimesh.exchange.stl.export_stl`（**二进制 STL=固定 float32**），坐标域 12.57 量级下分辨率 2^-23×2³≈**1e-6**——精确解释节点对 206/23775 间距；该间距 >Gmsh Geometry.Tolerance(1e-8) 故拒合并，病灶经约束恢复向下游传导。
- **管线级根治修复（下轮 p0/p1 修复轮，两行）**：写 STL 前顶点预合并（float64 域按 ~1e-5 容差 merge——写 float32 后变完全同坐标，Gmsh 可合并）；与 Gemini 的场钳位 eps_snap 互补（一个防 MC 边界插值近重合对，一个防场零点贴格点），双修入库。
