## 一、四个关键设计点的讨论与共识

### A. 卡片位置：独立侧栏卡（全票达成共识）
- **结论**：**采用独立侧栏卡（如「CAE 仿真工作台」），绝不修改任务流五步**。
- **依据**：
  1. 任务流五步（①设计 $\to$ ②候选 $\to$ ③制造检查 $\to$ ④导出 $\to$ ⑤试验分析）是轻量闭环的“交付语义”，受 `probe_taskflow_e2e` 等自动化探针严格保护；
  2. 混入外部环境配置与长文本命令复制会破坏任务流简洁性；
  3. **协同纽带**：在任务流第 ⑤ 步（试验分析）底部增设一个文字链接：“需生成仿真对照曲线？前往 [CAE 仿真工作台]”，实现场景无缝跳转。

### B. 参数映射：卡上显式双列对齐（全票达成共识，补充具体公式）
- **结论**：**卡片界面显式双列展示「平台设计参数 $\to$ 终端命令参数」，绝不黑盒隐式转换**。
- **必须明示的关键语义差异**：
  - 孔隙率：平台 `porosity`（百分比，如 75） $\to$ CLI `--por 0.75`（体积分数小数）；
  - 周期数：平台 `periods`（k） $\to$ CLI `--k`（1:1 映射）；
  - **核心易错点 · 分辨率换算**：
    - 平台 `resolution`（如 96）为全域总格数；
    - `sim` 管线的 `--R` 为**每周期格数**；
    - 换算关系：$R_{\text{sim}} = \text{resolution} / \text{periods}$（例如 96 / 8 = 12 格/周期）；
    - 双列显式打印 $R_{\text{sim}} = \lfloor \text{res} / k \rfloor$，并在卡片上注明该换算逻辑，彻底防范超大网格爆炸。

### C. 二期本地桥预埋：坚决不放 disabled 占位按钮（全票达成共识）
- **结论**：**践行 YAGNI 原则，一期只做清爽高效的“参数化命令一键复制器”，严禁出现灰置占位符**。
- **依据**：前端界面中无法点击的置灰按钮（如“启动本地求解中...”）会给初次访客带来“系统未完工/依赖故障”的负面心理暗示。将复制按钮状态维护好（点击后变绿提示“已复制到剪贴板！”）用户体验最优。

### D. 环境检测：提供一键复制的聚合检测脚本（达成共识并优化）
- **结论**：**提供轻量的一行流终端检测脚本，并给出明确的版本回显预期与排错指引**。
- **实施形式**：
  提供单个复制按钮即可跑完所有前置依赖的自检命令：
  ```bash
  python -c "import gmsh; print('Gmsh:', gmsh.__version__)" && abaqus whereami
  ```
  下方配 3 行微型状态对照提示：
  - `Gmsh: 4.15+` $\to$ 网格前处理就绪；
  - `ABAQUS/Standard 202x` $\to$ 求解器就绪；
  - 若报 `command not found` $\to$ 提示检查系统 PATH 环境变量。

## 二、工作台五段链路卡落地架构骨架

1. **第一段 · 几何状态锚定**：
   - 提取当前 UI 设计：`Gyroid` ｜ `k=2` ｜ `por=0.60` ｜ `H0=24mm`。
2. **第二段 · 网格生成命令**（依赖已采纳的 [p0 补丁](../../sim/p0_generate.py) 与 [p1 补丁](../../sim/p1_mesh.py)）：
   ```bash
   python sim/p0_generate.py --k 2 --R 24 --por 0.60 --out sim/out/g_k2_p60.stl
   python sim/p1_mesh.py sim/out/g_k2_p60.stl --lmax 0.5
   ```
3. **第三段 · 求解装配与执行命令**（基于 [T2 方案](../../collab/antigravity/2026-10-29-T2-ABAQUS-static-scheme.md)）：
   ```bash
   python sim/p2_static_setup.py sim/out/g_k2_p60.inp --specimen-h 24.0 --specimen-w 20.0
   abaqus job=g_k2_static input=sim/out/g_k2_p60_static.inp cpus=4 interactive
   ```
4. **第四段 · 契约数据提取命令**：
   ```bash
   abaqus python sim/p2_extract_csv.py --odb g_k2_static.odb --h 24.0 --w 20.0 --out specimens/csv/sim_g2.csv
   ```
5. **第五段 · 平台反演对照**：
   - 一键跳转至平台任务流第 ⑤ 步「试验分析」卡片，将 `sim_g2.csv` 拖入，直出 ISO 13314 模量与平台应力，完成数字孪生闭环。
