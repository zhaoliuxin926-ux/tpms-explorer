# 批十四：第三轮评估 P1-01/02/03——交付几何一致性（按评估修复顺序 1）

## 问题定义

评估（基线 c8a6054=当前 HEAD，独立探针+真实下载产物实证）三条交付失真，逐条复核全部成立：

- **P1-01 UI INP/polyMesh 全实心**：resolveExportPorosity 对 exactCapable（基础均匀设计！）
  返回 targetPorosity=undefined → buildVoxelModel 二分 `1-undefined=NaN` → 比较恒 false →
  bias 顶到 maxV+0.5 → 全固相。75% 设计导出 40³=64000 单元全实心盒子（实测 8000mm³）。
  三处调用同病：INP/polyMesh 块（main.ts:5427）+ CAE 验证套件（main.ts:5456）。
  制造卡与层切卡不受影响（显式传 s.porosity/100）。
- **P1-02 导入不完整**：①sanitizeDesignState 的 walk 按 `typeof src !== typeof defv` 过滤，
  specimenSizeMm 默认 null（typeof 'object'）→ 合法数值 20 被当类型不匹配删除——保存
  20mm 导入回退 3mm；②meshCont（外部容器）不属 AppState 且**无任何清除路径**（上传后
  只能刷新页面）——导入普通设计后容器仍激活，制造检查被拒、重存文件带错 notCaptured。
- **P1-03 脚本/VTI 丢显式总宽**：script-exporter py/m 的 cell_size 双职（频率 k+物理总宽
  mm，legacy 下同值）——显式宽度时物理侧全错（origin/spacing/端板钳制/换算）；VTI 的
  cellSizeMm 传 s.cellSize → 20mm 设计出 3mm 网格。

## 物理模型与研究目标

同前两轮一致主题的延续：**跨出口几何同一性**——INP 体素孔隙率应≈设计值；设计文件导入=
完整状态替换（含 nullable 显式宽度与外部资源清场）；py/m/VTI 复现出口的毫米尺度=交付尺度。

## 我的假设与归因猜想

1. P1-01 正确修法在调用侧非体素侧：体素模块的契约本就是 targetPorosity 二分（自洽语义），
   exactCapable 的 undefined 是"网格路径复用 resolveExportPorosity"时的类型谎言
   （`as number` 掩盖）——调用侧显式传 s.porosity/100（体素对自身离散场二分=正确口径，
   iso 仅作初值），体素侧加 fail-closed 守卫（非有限 targetPorosity 即 throw）。
2. P1-02 的 nullable 修复=walk 显式处理 defv===null 分支（接受有限数或 null）；容器清场=
   applyDesignFile 重置 meshCont=null+status 文案+file input 复位（替换语义对"文件里没有
   的外部资源"同样成立——不能静默继承另一设计的容器）。
3. P1-03 py/m 拆双变量：`cell_size`=k（频率，全部场求值数学不动）+ 新 `width_mm`=显式总宽
   （origin/spacing/端板钳制 0.4·W/z_band 换算/mm→rad 因子 2π/W）；legacy（W==k）时
   输出与现状逐字相同（等值替换）。VTI 一行改传 effWidthMm(s)。

## 方案

1. main.ts：三处 `targetPorosity: xxx.targetPorosity as number` → `targetPorosity: s.porosity / 100`；
2. voxel-model.ts：构造前守卫 `if (!Number.isFinite(params.targetPorosity) || params.targetPorosity <= 0 || params.targetPorosity >= 1) throw`（NaN 类型谎言 fail-closed）；
3. sanitizeDesignState walk：`if (defv === null)` 分支（null/有限数接受，否则丢弃）；
4. applyDesignFile：state 替换成功路径上 meshCont=null + `#meshcont-status` 文案 + `#meshcont-file` value 复位；
5. script-exporter py/m：头部加 `width_mm`，物理侧全换（保留 cell_size=k 频率语义）；MATLAB 同；
6. main.ts VTI 调用：`cellSizeMm: effWidthMm(s)`；
7. probe_delivery_p3.mjs（一次性）：①schwarz p75 sw=20 导 INP → 解析单元数+头部固相率
   （期望 ~16000 单元/固相率~0.25，绝非 64000/1.0）；②保存 sw=20 设计→上传小容器→导入
   →sw-value=20mm+容器状态清空；③导 py+vti → py 含 width_mm = 20+vti cellSizeMm=20
   （origin -10/spacing 20/48）；④0 pageerror。
