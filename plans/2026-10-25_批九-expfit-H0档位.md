# 批九：UI 试验反演 H₀ 档位防呆（S1_G60 试验日风险收口）

## 问题定义

fit-batch（CLI）有 H₀ 档位校验 `{12,24,34}±1` 越档告警（批一 P3），**UI「试验曲线反演」
位移-载荷路径没有**（main.ts:698 直接读输入默认 L₀=12，无任何校验/披露）。用户拿
S1_G60 CSV（协议 ×2.5 档：H₀=24mm、截面 20×20=400mm²）在 UI 反演忘改 L₀/A₀ 时，
应变换算错 2×、应力错 4×，E* 静默错 8×——试验数据反演的可追溯闭环断点。

## 物理模型与研究目标

位移-载荷→应变-应力换算：ε=ΔL/L₀（线性 ∝1/L₀）、σ=F/A₀（∝1/A₀）。L₀/A₀ 是换算
的唯二自由参数，必须与试样实测一致——UI 侧至少要做到"用了什么口径看得见、越档有告警"。

## 我的假设与归因猜想

1. UI 默认 L₀=12/A₀=100 是通用缺省（H₀ 12 档试样），不能武断改成 24——防呆的正确
   形态是**越档告警+口径披露**（结果文本可见用了什么 L₀/A₀），不是猜默认。
2. 档位表 {12,24,34}±1 与 fit-batch 同源（同一条协议口径）；UI 复制该常量即可，
   无需引 CLI 模块（避免为一条 if 建桥）。

## 需要的素材与数据

- [x] fit-batch.mjs:75 越档措辞（复用）；S1_G60=24mm/1.44mm/min（memory+协议）
- [x] check_expfit_card.mjs 无 df 覆盖（grep 空）——扩展同文件
- [ ] 无需新素材

## 方案

1. main.ts bindExperimentalFit：isDf 时算 hWarn=![12,24,34].some(v=>|v−l0|≤1)；
   越档在结果文本**头部**加 ⚠ 行（复用 fit-batch 措辞）；df 模式结果**尾部**追加
   口径披露（位移-载荷口径：L₀=…mm · A₀=…mm²）。strain-stress 模式不变。
2. check_expfit_card.mjs 扩 df 用例 ×2：L₀=24/A₀=400（S1_G60 标称）→ 无 ⚠ + 口径行
   含 L₀=24 + E* 恢复与应变-应力基线同值（换算互逆）；L₀=30 越档 → ⚠ 出现 + E* 按
   30/24 比例放大（固定位移-载荷数据重解释，应变压缩 σ-ε 斜率放大）。
3. run_all 标签 4 项→6 项连带。fit_audit（模块层 21 断言）不动。
