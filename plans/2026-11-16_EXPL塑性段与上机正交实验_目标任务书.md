## 目标七问

### 1. 目的（为什么要跑这一程）
- [docs/fea-calibration.md](../docs/fea-calibration.md) 目前仅认证了线弹性 $E_{\text{eff}}$（T4 双点盲测误差 $-1.07\%$ / $-0.90\%$，实测 $\bar{\rho}$ 口径 $<0.3\%$），而 $R_{p0.2}$ 与平台应力 $\sigma_{\text{pl}}$ 仍标记为「经验外推」。
- 本程目标是拿到 T4 独立显式动力学链（ABAQUS/Explicit C3D10M）的实算塑性曲线，完成 $R_{p0.2}$ 代理分级升档并触发下一次 Gemini 外部评审；同时为后续 S1 实物试样上机压缩预留四步正交实验数据对接接口。

### 2. 完成态（机器可判的验收标准）
1. **Explicit 求解产出**：完成 `gyroid_k2_R20_p70`（主锚）与 `p50` 在 `--strain 0.30 --nlgeom --plastic --contact --friction 0.3 --explicit 5.0 --mass-dt 2e-7` 下的完整求解。
2. **准静态能量比硬判据**：
   - 主承载平台段 `ALLKE / ALLIE < 10%`（目标 $< 2\%$）；
   - 人工伪应变能 `ALLPW / ALLIE < 1%`。
3. **曲线归档与反演**：提取 `*_EXPL_curve.csv` 归档至 `sim/csv_archive/`，经 `fit-batch.mjs` 真实内核计算出 $R_{p0.2}$ 与平台应力 $\sigma_{\text{pl}}$，不保留超过 100 MB 的 `.odb` 原始文件进工作区（与 `bf3b60e` 瘦身纪律一致）。
4. **文档升档与门禁全绿**：将实测对比数据写入 `docs/fea-calibration.md`「T4 独立链复现注记」及 `docs/fit-report-expl.md`，并跑通 `docs_consistency_check.mjs`（`349 PASS / 0 FAIL`）与 `schema_check.mjs --fast`。

### 4. 反作弊禁令（绝不允许的捷径）
- **禁止调包参数凑数**：严禁为压低 `ALLKE/ALLIE` 而擅自放大材料密度（`PLA_DENSITY`）或篡改 `PLA_PLASTIC` 硬化表而不披露。
- **禁止裁剪 CSV 异常点**：不得手工删除提取曲线里的初始振荡或平台波动点。
- **禁止跳过能量比核对**：若 `ALLKE/ALLIE >= 10%`，该算例不得标注为「准静态认证」，必须触发时间放大（`--explicit 10.0`）或减小 `--mass-dt 1e-7` 敏感性对照。
- **禁止推大文件入库**：任何 `.odb`、`.stt`、`.prt` 不得入 Git；CSV 归档前需确认体积在 KB 级。

### 5. 地界与熔断机制（时间盒 + TTL 跳数熔断）
- **15 分钟试错时间盒**：前处理组装、脚本报错或求解器卡死调试，单轮超过 15 分钟无实质中间产物必须停手排查 CPU/墙钟比或上报挂起。
- **TTL 跳数熔断（上限 3 轮）**：针对同一算例的网格畸变/前处理拒收或接触发散，最多允许连续调参重试 3 轮（TTL = 3，人工介入确认前不重置计数）；第 3 轮仍失败即触发熔断并生成挂起报告。
- **只读保护**：`tpms/tpms-platform/src/**` 与 `docs/HONESTY_BOUNDARIES.md` 在本任务中禁止顺手改动（除非因最终数据推翻旧边界）。
