# 批六：UI 独立尺寸支持——解锁 Pareto/逆设计采用入口（审查 #2 UI 链收口）

## 问题定义

批一统一尺寸契约时，UI 保持「1 period=1mm」并**阻断**了 Pareto 前沿点采用与逆设计应用
两个入口（单胞≠1mm 候选不可表示，阻断 toast 给 CLI 等效命令）。bugs.md 在案：
「Pareto/逆设计两入口待 UI 独立尺寸批次解锁」。批五任务流卡 ② 跳到 Pareto 后点击前沿点
即被拦——任务流在 ②→① 断链。本批给 UI 增加显式试样总宽（尺寸契约三量的真源量），
采用入口按批一同款绑定（periods=3 + 总宽=3×候选单胞）解锁。

## 物理模型与研究目标

尺寸契约三层量已在 units.ts 定案（总宽 specimenSizeMm 真源 / 周期数 periods / 单胞=
总宽÷periods 派生）。物理影响链：wc 域几何**不随宽度变**（sin(kx) 频率编码），变的只是
wc→mm 因子 f = 总宽/(2π)；所有 mm 口径量（STL/INP/3MF/G-code 坐标、表面积 mm²、
体积 mm³、Sv mm⁻¹、渗透率 m²、端板 wc 换算、制造检查 h、卡尺读数、尺寸标注）按 f 换算。
κ∝单胞² 的 Pareto/逆设计预测在 单胞=总宽/periods 时成立——采用即兑现。

## 我的假设与归因猜想

1. 宽度变更的正确缓存语义是 **cacheKey 加 SW 段**（整键失效→worker 重算）：geoCache
   缓存的 surfaceArea 是 worker 按 periods 因子算好的 mm 口径绝对值（surface-nets.ts:1484），
   若只改显示层换算，宽度变更会命中旧缓存直接展示错误指标。整键失效的代价（宽度是低频
   显式操作）远小于"缓存命中旧指标"的静默错误。
2. wc 几何与分辨率需求都不随宽度变（每周期格数密度不变）——hdResolution/导出升档逻辑
   无需感知宽度；宽度只进"物理口径"消费点，不进"几何形状"消费点。
3. 容器 STL（meshCont.scale）与 MT 一次性管线（radial-grad/region 归一域）有固有尺度，
   与 CLI 批一拒绝组合同源——导出路径已有 `meshCont ? meshCont.scale : …` 分支天然豁免；
   INP+容器静默回退 cube 是登记在案的预先存在问题（不属本批）。

## 方案（宽度=可选覆盖，null=自动/legacy）

### A. 状态与单位真源

1. types.ts AppState + DEFAULT_STATE：`specimenSizeMm: number | null`（null=自动，即
   1 period=1mm，总宽=周期数——默认路径全链字节语义不变）。
2. units.ts 新增 `effectiveMmFactor(periods, specimenWidthMm | null)`：null→
   wcToMmFactor(periods)，否则 wcToMmFactorByWidth(width)。唯一换算入口。
3. geo-cache.ts cacheKey 追加 `|SW{auto|数值}`（宽度变更→全键失效重算，指标随新因子）；
   geometryStateKey/buildRequestKey 经 cacheKey 自动继承。

### B. worker 指标链（BuildParams.mmPerWc）

4. BuildParams 加 `mmPerWc?: number`（缺省=旧语义）；四构造点（main.ts 1092/2353/2538/2605）
   传 `effectiveMmFactor(s.cellSize, s.specimenSizeMm)`。
5. surface-nets：computeSurfaceArea/computeEnvelopeVolume 第三参从 cellSize 改为显式
   factor（physics/surface-area.ts 签名对齐，全仓唯一调用方就是 surface-nets——已核实）；
   `params.mmPerWc ?? wcToMmFactor(params.periods)` 兜底。meshSdf 容器分支 envVolume
   不动（容器固有尺度、与宽度互斥）。
6. periodic-surface.ts:462 RVE PBC mm 换算：加可选 mmPerWc 参数同兜底（RVE 导出域=
   全 wc 域=periods 周期，总宽口径一致；PBC 配对在 wc 坐标不受影响）。

### C. main.ts 消费点（container 分支保持 meshCont.scale 原样）

- 425 endplate epWc、768 制造检查 hMm、1803 卡尺、5125 STL/5130 VTK/5136 GLB/5141 3MF/
  5150 gcode/5184 cfdstl/5207 RVE/5341 pkg、5248 INP specimen=总宽、bbox 标注两调用点
  （2751/3735，bounding-box-annotation 改收总宽 mm）、pkg manifest sizeContract 三量。

### D. 采用入口解锁（批一同款绑定）

- Pareto 前沿点（1004）与逆设计应用（3858）：阻断块改为
  `setState({type, porosity, cellSize: 3, specimenSizeMm: 3×单胞, ...})`——periods=3
  与 CLI 推荐绑定一致（k6 非标定域教训），总宽=3×单胞使单胞 mm 精确还原，κ∝单胞²
  预测兑现；toast 披露总宽与单胞。hybrid 点维持"族 A 写回+手动对齐"披露。
