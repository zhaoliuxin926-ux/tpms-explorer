# 批十一：外部评估三 P1 一致性修复（导入替换语义/渐变导出单源/体素消费端守卫）

## 问题定义

外部评估（基线 9db2c30，动态证据齐全）复现三条跨模块一致性缺陷，当前 HEAD 逐条核实**全部仍成立**（且 #3 比报告更广——HD 升档路径同病）：

1. **P1 导入继承当前高级设置**：applyDesignFile 走 shareUrl→parseURLParams→合并式
   setState；保存时关闭的特性（端板/混合/渐变）不进 URL→导入后残留当前页面的同类
   设置——同一文件在不同页面恢复出不同几何。交付包内 design.json 同病。文件仅有
   format 无载荷也被接受。
2. **P1 制造检查检查了另一套几何**：mfg 卡的 buildVoxelModel 未传端板/混合/渐变等
   配置，且 VoxelModelParams 本就不支持（文档化"均匀多孔段语义"）——开启这些配置
   的设计审计出的是均匀几何，报告却绑定完整设计指纹标"已完成"。
3. **P1 渐变设计导出级重建丢渐变**：主重建 isoGrad 时 targetPorosity=undefined+
   isoGrad=makeZGrad(...)；而 HD 升档与导出级重建都走 resolveExportPorosity
   （isoGrad→exactCapable=false→全局二分回退+无 isoGrad 参数）→ 渐变在 HD 帧/导出
   产物变成均匀几何，函数仍返回成功。**比报告更广：HD 升档路径同病**。

## 物理模型与研究目标

跨路径参数投影一致性：屏幕几何、交付 STL、制造检查体素、INP 体网格必须对同一状态
消费同一套 {iso, targetPorosity, isoGradSpec} 三元组与同一场配置；不可表示的配置必须
fail-closed（对照 10-02 M4 meshCont 先例），不许静默回退均匀语义。

## 我的假设与归因猜想

1. #3 的结构性修法是**三元组单源**：resolveBuildTrio(s) 返回 {iso, targetPorosity,
   isoGradSpec}（isoGrad→iso=baseIso+undefined 二分关闭；否则沿用 resolveExportPorosity
   的 exact/二分逻辑），主重建/HD 升档/导出重建三消费点全部改喂 trio——非渐变路径
   三元组恒等（字节级不变），渐变路径三处全部恢复与主重建同口径。
2. #1 的验收语义是"经过校验的完整状态替换"：优先 file.state 快照（保存时完整态），
   递归形状校验（键=默认态键、类型匹配、核心数值域钳制）后**重置默认再合并**——缺省
   键回落默认=关闭态特性被显式清掉；仅 format 无 state/shareUrl→拒收保持原状态。
3. #2 首档按验收允许的"明确拒绝"路径：voxelUnsupportedReasons(s) 单源守卫
   （容器/混合/渐变场/端板/梯度壳/分形/神经/非欧映射），制造检查与 INP/polyMesh
   两个体素消费端共用——与 10-02 M4 的 meshCont fail-closed 同型。

## 方案

### 修三（先做：主重建字节级锚最硬）
- resolveBuildTrio(s) 单源；三消费点改喂：rebuild 内联（isoOut/targetPorosity 初始化+
  isoGrad 参数）、scheduleHdUpgrade、ensureExportGradeGeometry。lastBuildUsedExact
  语义保持（渐变=false）。非渐变设计产物字节级不变。

### 修一
- applyDesignFile：state 快照优先（sanitizeDesignState：递归形状校验+porosity/cellSize/
  thickness/slice/endplateMm/specimenSizeMm 数值域钳制）→ pushHistory → setState(DEFAULT)
  → setState(patch)（替换语义）；无 state 时退化 shareUrl（现行为，向后兼容旧文件）；
  两者皆无 → throw（保持原状态）。toast 披露替换语义。

### 修二
- voxelUnsupportedReasons(s)：meshCont/混合/渐变场/端板>0/梯度壳/分形/神经/非欧映射
  → 理由清单；mfg 卡与 INP/ofmesh 共用，非空即 toast 拒绝不产出。

### 探针（一次性 probe_consistency_p1.mjs）

  （替换语义）；
- 渐变导出：同页两次导出 STL（关/开渐变，createObjectURL 捕获）→ 二进制哈希与三角
  数必须不同（bug 形态=恒等）；
- 守卫：渐变/混合态跑制造检查 → 拒绝文案出现且 ③ 徽章不置 done。
- 0 pageerror。
