# 第二批：#8 参数 JSON 补全 + 设计文件保存/导入（实用性审查第二批）

> 来源：审查 #8——sidecar parameters 缺 endplateMm/isoGrad/manifold/stress/hierarchical/neural 六项；reproducibility.url 用地址栏而非按当前状态构造的分享链接；无完整设计文件保存/导入（保存→关闭→导入→重建不可达）。用户已排为第二批；"怎么合适怎么来"授权下执行。

## 问题定义

参数 JSON 无法完整重建复杂设计（六项几何配置缺失+URL 语义错）；UI 无设计级保存/导入闭环。

## 方案（最小且诚实）

### A. Sidecar 补全（bibtex-sidecar.ts + main.ts 三调用点）

1. `parameters` 补 6 项：endplateMm/isoGrad/manifold/stress/hierarchical/neural（含嵌套对象原样序列化）；version '2.1'→'2.2'。
2. `generateJSONSidecar`/`generateBibTeX` 增 `shareUrl` 参数；reproducibility.url 与 BibTeX url 改用调用方传入的 `buildShareURL()`（按当前状态构造，非地址栏）；三调用点连带（配图 4856/bib 5140/json 5146）。

### B. 设计文件（导出+导入）

1. **导出**：导出中心新条目 `data-export="design"`（纯参数无需几何，不过水密门）→ `tpms-design-<type>-p<porosity>.json`：
   - `format: 'tpms-design/1.0'` + platform 版本 + savedAt
   - `shareUrl`（buildShareURL 全参数）+ `formula`（完整 customFormula，不受 12KB URL 帽——设计文件里公式即设计本体）
   - `state`（AppState 完整快照，人读+工具核对）
   - `notCaptured`：动态（meshCont 自定义容器 STL 需重传）+ 静态（radial-grad/region 面板一次性管线不在 AppState）
2. **导入**：工具栏 btn-import（btn-share 旁）+ 隐藏 file input → `applyDesignFile`：
   - JSON.parse + format 白名单校验（未知格式结构化拒绝）
   - **解析复用 `parseURLParams(new URL(shareUrl).search)`**——分享链接解析器即现成的枚举白名单+域钳制（state_url_audit 17 断言背书），零新校验面；formula 字段随后覆盖（绕 URL 帽）
   - pushHistory → setState → syncUI → updateBadges → scheduleRebuild+scheduleHdUpgrade（与逆设计应用同链）
   - toast 报告导入结果 + notCaptured 提示（容器需重传）
3. 导入的 customFormula 经既有方程解析沙箱求值（evaluator_check 37 门背书，无新增攻击面）。
