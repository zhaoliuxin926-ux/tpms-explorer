> 用户选择「两个都做」：① 把分组做成可跳章的演示章节；② 整页 PDF 导出。

## 一、分组 = 可跳章演示章节
原「分组巡演」是一次性顺序自动播放，现在升级为带章节进度条的可跳章播放器。

- 顶部出现毛玻璃 `tourBar`：
  - 左：`◀ 分组巡演 ▶`（上一章 / 下一章）
  - 中：**章节胶囊**（每个分组一个，带其分组色圆点，当前章青框高亮，可横向滚动）
  - 右：`⏸/▶` 播放暂停、`✕` 退出
- 任意点击章节胶囊即跳到该章（召回并聚焦主阶段）；当前巡演项在分组面板里青框高亮（`gp-tour`）。
- 键盘（巡演进行中）：`,` 上一章、`.` 下一章、`空格` 暂停/继续、`Esc` 退出。
- 引擎重构：`runGroupDemo` 由 `for + await sleep` 改为基于 `setTimeout` 的状态机（`groupTour = { idx, timer, paused }`）。跳章后从新章继续自动推进；暂停后停在当前章；退出时清理定时器并复位演示态。

## 二、整页 PDF 导出（纯离线 · 矢量高保真）
工具栏新增「📄 PDF」。

- **实现上没有内联任何第三方库**——这是刻意的更优取舍：
  - 复用既有的 `buildSnapshotSVG()`（自包含矢量快照），注入一个隐藏的 `#printStage` 打印舞台（含标题/副标题）；
  - 配 `@media print` 样式：隐藏全部 UI 浮层（工具栏、缩略图、分组面板、巡演条、帮助、光标层……），仅显示矢量图；
  - 调用 `window.print()`，由**浏览器打印引擎**输出 PDF——在打印对话框选「另存为 PDF」即得整页矢量 PDF。
- 为什么不用内联 html2canvas / jsPDF：内联会让单文件膨胀数百 KB、破坏纯离线轻量性；且 html2canvas 对这种「SVG + Canvas + 毛玻璃 `backdrop-filter` + CSS 变换」混合图面的还原度很差。浏览器打印引擎直接渲染真实 DOM，矢量、清晰、零依赖。

> 若日后需要「一键直接下载 .pdf 文件、绕过打印对话框」，可再评估内联 `svg2pdf.js`（SVG→PDF 矢量路径），届时会带来体积代价，按需开启。
