# 第十四轮 · 选择 / 精度 / 配色（claude-code-workflow.html）

用户「全做」上一轮给出的三个方向，作为高级开发工程师一次性补齐。全部在编辑模式下生效，且**不破坏**已有的拖拽 / 连线 / 协作（awareness）逻辑。

## 1. 多选 + 框选（Marquee）
- `Shift` 点节点：逐个增删选区（青色描边高亮）。
- 空白处按住拖拽：画出虚线选框，相交节点全选；按住 `Shift` 拖框为「叠加」不替换。
- 选区在任意重渲染（含 CRDT 并发合并）后自动恢复。

## 2. 整组拖拽 / 删除
- 拖选区内任一节点 → 整组同步平移（保留相对偏移）。
- `Delete` / `Backspace`：整组删除；`Ctrl/⌘+A`：全选；`Esc`：清空选区（并取消连线）。
- 组的每个节点位置在 CRDT 模式各自 `setNodeField(x/y)` 合并，LWW 模式统一 `broadcast()`。

## 3. 网格吸附 + 对齐参考线
- 工具栏「网格吸附」开：落点按 20px 网格量化。
- 关闭时启用**智能对齐**：被拖节点与其它节点的左/中/右、上/中/下边接近 6px 自动吸附，全屏绘制青色虚线参考线。
- 吸附与对齐互斥（开网格不打参考线）。

## 4. 节点配色分组
- 选中节点后弹出毛玻璃「配色」浮条（8 色 + 清除），一点即给整组节点左侧描边着色。
- `accent` 入节点数据：CRDT 经 `setNodeField('accent')` 合并，LWW 经 `broadcast` 同步；缩略图节点块按 `dataset.accent` 分色。

## 关键实现
- 框选在 `#diagram` 空白 `pointerdown` 起手，与节点自身 `pointerdown`（起手拖拽）用 `closest('.box')` 区分，互不干扰。
- 整组拖拽以 `drag.group[]` 数组统一驱动；`renderDiagram` 末尾 `applySelection()` 重放选区防丢失。
